# Skills avancés

Ces skills ne servent pas au montage de tous les jours, donc ils ne sont pas chargés par défaut :
- `contribute-catalog`
- `remotion-to-hyperframes`
- `website-to-hyperframes`
- `text-to-lottie`
- `typegpu`
- `three`

Pour en activer un, dis à ton IA « active le skill <nom> » : elle copie son dossier dans
`.claude/skills/` (et `.agents/skills/` pour Codex), puis relance `node scripts/sync.mjs`.
